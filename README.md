# Sung Won Field App

작업일보와 자주검사 기록을 작업자가 웹에서 입력하고, 관리자가 취합해서 보는 실사용형 웹앱 초안입니다.

## 실행

```powershell
npm start
```

또는 Node.js만 있을 때:

```powershell
node server.js
```

기본 포트는 `3000`입니다.

- 작업자 입력: `http://서버주소:3000/`
- 관리자 취합: `http://서버주소:3000/admin.html`

## 저장 위치

입력 데이터는 `data/db.json`에 저장됩니다.

## 운영 메모

현장 실사용 시에는 이 폴더를 사내 서버 또는 클라우드 서버에 올리고, 방화벽에서 `3000` 포트를 허용하거나 IIS/Nginx 뒤에 붙여 사용하면 됩니다. ERP가 CSV 업로드를 받는다면 관리자 화면의 CSV 내보내기를 ERP 양식에 맞춰 조정하면 됩니다.
