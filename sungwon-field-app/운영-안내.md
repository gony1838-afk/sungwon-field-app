# 성원 현장 기록 앱 운영 안내

## 접속 주소

같은 사내망/와이파이에서 접속합니다.

- 작업자 입력: `http://192.168.70.194:3000/`
- 관리자 로그인: `http://192.168.70.194:3000/admin.html`
- 기본 관리자 비밀번호: `1234`

## 서버 시작

PowerShell에서 앱 폴더로 이동 후 실행합니다.

```powershell
.\start-server.ps1
```

## 서버 중지

```powershell
.\stop-server.ps1
```

## 상태 확인

```powershell
.\status-server.ps1
```

## 데이터 위치

입력 데이터는 아래 파일에 저장됩니다.

```text
data\db.json
```

운영 중에는 이 파일을 주기적으로 백업하세요.

## 핸드폰 접속이 안 될 때

- 핸드폰이 같은 사내망/와이파이에 연결되어 있는지 확인
- PC 방화벽에서 TCP 3000 포트가 허용되어 있는지 확인
- PC가 절전/종료되면 접속할 수 없습니다
