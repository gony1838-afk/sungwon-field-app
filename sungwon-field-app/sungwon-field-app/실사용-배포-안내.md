# 성원 작업일보 앱 운영 전환 안내

## 운영 방향

6월 말까지는 Render 무료 서버를 테스트 링크로 사용하고, 7월 실사용부터는 회사 내부 서버로 이전하는 방식을 권장합니다.

```text
6월 테스트: Render 무료 서버
7월 실사용: 회사 내부 서버
```

이 방식이면 작업자는 테스트 기간에도 휴대폰 링크로 입력할 수 있고, 7월부터는 외부 클라우드 저장소 비용 없이 사내 서버에서 운영할 수 있습니다.

## 6월 Render 테스트 방식

Render 무료 플랜은 테스트용으로 적합하지만, 서버 재시작이나 재배포 시 내부 저장 파일이 사라질 수 있습니다. 따라서 6월 테스트 기간에는 관리자 화면에서 매일 ERP CSV를 다운로드해 백업하는 방식으로 운영합니다.

Render 환경 변수:

```text
PORT=3000
ADMIN_PASSWORD=원하는관리자비밀번호
```

테스트 접속 주소 예시:

```text
작업자 입력: https://배포주소/
관리자 로그인: https://배포주소/admin.html
```

휴대폰에서는 링크 접속 후 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 7월 사내 서버 전환 방식

회사 내부 서버에 설치할 때는 데이터가 사라지지 않도록 `DATA_DIR`을 서버의 백업 대상 폴더로 지정합니다.

내부 서버 환경 변수:

```text
PORT=3000
ADMIN_PASSWORD=원하는관리자비밀번호
DATA_DIR=D:\SungWonFieldApp\data
```

사내 접속 주소 예시:

```text
작업자 입력: http://사내서버주소:3000/
관리자 로그인: http://사내서버주소:3000/admin.html
```

전산 담당자에게 요청할 내용:

```text
현장 작업일보 웹앱을 7월부터 사내 서버에서 운영하려고 합니다.

필요 조건:
- Node.js 18 이상 설치
- 앱 실행 폴더 생성
- DATA_DIR 데이터 폴더 생성 및 백업 대상 등록
- 내부망에서 접속 가능한 주소 또는 서버 IP 안내
- 3000번 또는 지정 포트 방화벽 허용
- 서버 재부팅 후 앱 자동 실행 등록
```

## 데이터 이전

6월 Render 테스트 데이터는 실사용 데이터로 보지 않고 테스트 데이터로 취급하는 것이 안전합니다. 필요한 경우 관리자 화면에서 CSV로 내려받아 참고 자료로 보관합니다.

7월 사내 서버에서 새로 시작할 때는 내부 서버의 `DATA_DIR/db.json`이 정식 운영 데이터가 됩니다.

## 현재 기능

- 작업일보 입력
- 한국어/베트남어 전환
- 품번 마스터 경고 표시
- 불량일보 자동 취합
- QC 수정
- 작업일보 수량 수정
- ERP CSV 다운로드
- 관리자 비밀번호 로그인
- 관리자 화면 인쇄
- 안드로이드/아이폰 홈 화면 추가 지원
